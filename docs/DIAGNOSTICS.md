# 运行问题排查

日志用于还原已观察到的执行过程，不授予网络许可，也不能单独证明当前保护正常。
排查时先对照事件时间、构建标识和启动标识，再检查实际执行回执。不要仅凭
“配置保存”“命令发出”或进程存在判断已经断流。

## 导出

在新版应用的“事件记录”页选择“导出诊断包”。导出只读取本地文件，不运行网络
检测、不改 VPN、不启动应用。需要选择一个新文件；导出不会覆盖已有文件。

也可以显式调用安装后引擎的 `diagnostic-export --export <新文件的绝对路径>`。
导出路径不能经过符号链接。文件权限为当前用户读写。既有 `logs --export` 的
事件导出格式保持不变。

诊断包包含最近的结构化事件、监督器/网关状态摘要、初始化与桌面入口记录、
系统网关事件和安装阶段摘要。记录经过字段白名单筛选，不导出账号、凭据、
完整 URL、IP、节点名称、文件路径/内容、命令参数或任意错误原文。
安装器的原始终端输出不纳入诊断包。

每个来源单独标明缺失、不可读、格式错误或截断；文件尾部最多读取 256 KiB、
最多保留 200 条记录，单个对象数组最多 64 项，总导出小于 2 MB。
不存在的日志表示没有可用证据，不能解释为“没有故障”。导出中的状态文件可能
是旧快照，应核对 `captured_at`、执行器启动标识、策略和命令序号。

## 记录位置和关联方法

| 记录 | 位置 | 主要用途 |
| --- | --- | --- |
| Rust 事件 | `~/Library/Application Support/ClaudeWatch/switcher/*events*.jsonl` | 环境变化、许可、建连/断流阶段、实际回执、执行/落盘失败 |
| 初始化 | `~/Library/Application Support/ClaudeWatch/logs/initialization*.jsonl` | 八项检查的开始、结果、失效、重试及具体失败代码；第 2 项保留采样/身份详细证据 |
| 桌面入口 | `~/Library/Application Support/ClaudeWatch/logs/controlled-entry-*.jsonl` | 启动、文件/URL 交接和目标回复；仅记录数量、状态及系统错误码 |
| 系统网关 | `/Library/Logs/ClaudeWatchGateway/events.jsonl*` | 安装准备、监听身份、句柄交接及拒绝原因；用实际二进制 SHA256 对照包组件 |
| 重装 | `~/Library/Logs/ClaudeWatchInstaller/reinstall-*/` | `run.json` 保存各阶段结果/退出码；构建和安装输出分别保留，不受 Watch 数据重置清除 |

Rust 事件的 `build_identity` 包含应用版本/build、源码提交、工作树是否有修改和
源码摘要。构建前采集，构建后重新核验；源码在编译期间变化会停止打包，避免
把混合版本标成同一版。缺少元数据的旧包/开发测试进程保持未知。元数据仅供诊断，
不能替代二进制完整性或身份认证。

通道记录使用 `producer_boot_id`、`executor_boot_id`、`family`、`session_id`、
`flow_id`、策略摘要、许可代次和命令序号串联。`time` 是记录时间；回执中的
`source_observed_at` 是实际执行观察时间。根据 `component` 和 `stage` 在对应
源码模块查找分支，`code` 保留原错误码，`reason` 是固定的脱敏说明。
任意原始错误文本可能包含凭据，所以不会直接落盘。

## 容量和失败边界

- Rust 复用已有按容量轮转的日志流，通道生产者只向容量 128 的队列非阻塞投递。
  磁盘写入不进入断流关键路径。队列丢弃、写入失败和状态保存失败可在日志健康
  字段及事件页看到；恢复写入后会记录此前丢失计数。
- 初始化、桌面入口的每个日志命名空间最多保留 16 个文件，每个最多 256 KiB。
  文件私有并拒绝通过符号链接写入；文件锁被占用时立即报告日志错误，不等待锁。
  这些少量界面日志仍同步写入，不应描述为完全异步。
- 系统网关保留当前及两份轮转文件，每份最多 1 MiB。运行时监听事件使用有界
  异步队列，日志失败不改变身份认证或句柄交接的业务结果。
  队列丢弃与事件写入失败在恢复可写后记录计数；没有新连接时也会重试保存该摘要。
- 安装器保留最多 5 组已知运行目录，单阶段输出最多 512 KiB 加一份轮转。
  文本副本会过滤常见敏感内容，但不能承诺任意第三方构建输出绝对不含敏感信息；
  共享排障时优先使用诊断包中的结构化摘要。
- 强制退出、掉电、磁盘不可用时，最后未写入的记录可能丢失；日志不是零丢失审计
  账本。无法写入时如实显示不完整，不阻塞保护，也不伪造成功。

自动测试验证的是隔离夹具和源码接线。正式安装后的后台权限、长期轮转、异常
重启和真实客户端断流仍需独立实机验收。
