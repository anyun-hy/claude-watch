### DNS / WebRTC 故障诊断（2026-10-30）

- 主窗口新增私有逐轮日志：`~/Library/Application Support/ClaudeWatch/logs/leak-diagnostics-<UUID>.jsonl`。固定事件记录自动刷新等待/跳过、检测来源及随机轮次编号、WebView 是否附着、导航/脚本/阶段/回执、检测结果和提交结果；相同调度状态最多每 5 分钟重复记录一次。后台提交的错误分类按时间关联，轮次内事件使用 `run_id`。仅允许固定事件、布尔值、时间和版本号，不写 IP、DNS 令牌、节点、账号、URL、原始响应或错误文本。
- 单文件最多 50,000 条，随后创建新文件并保留旧文件；日志不会自动清理，需要磁盘空间。写入失败只记系统日志，不改变检测、保护或放行判断。IPLeak 请求失败额外区分超时、网络错误、HTTP 状态错误和响应无效；不能从这些分类保证推断外部网络故障的根因。
- 受控会话后台 worker 将固定阶段写入受限通道；仅在 worker 采集不完整或执行失败时，后台校验事件白名单并写入 `switcher/diagnostic-events.jsonl`，按同一随机 `action` 关联，输出绝不含原始 stderr。其他后台会话/上下文变化沿用既有后台事件。日志会轮转；若进程在记录落盘前退出或日志无法写入，仍可能缺少证据。
- 这些修改尚未随应用安装；隔离测试、源码编译和真实安装后验收分开报告。不要把模拟 WebKit 结果或日志存在等同于真实网络、关窗保护和所有故障均已定位。
